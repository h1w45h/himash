# Сигналы из космоса

Telegram-бот платной подписки на канал с сигналами по ставкам.

- Продаёт подписку за Telegram Stars (⭐), тарифы задаются в `.env`.
- После оплаты выдаёт ссылку в закрытый канал; заявку на вступление бот одобряет, только если подписка активна.
- Напоминает за несколько дней до окончания подписки.
- Когда подписка истекла, удаляет пользователя из канала (он может вернуться, оплатив снова).
- Удаляет из канала тех, кто попал туда без подписки.
- Админ отправляет сигналы в канал командой `/signal`, выдаёт и отключает подписки `/grant`, `/revoke`.
- Все оплаты, выдачи, отключения и кики пишутся в таблицу `audit_log`.

## Настройка

1. Создайте бота у @BotFather и возьмите токен.
2. Создайте закрытый канал, добавьте бота администратором с правами «Блокировка пользователей» и «Приглашение по ссылке».
3. Узнайте ID канала (вида `-100...`) и свой Telegram ID (например, через @userinfobot).
4. Скопируйте `.env.example` в `.env` и заполните.

## Запуск

Через Docker:

```bash
docker compose up -d --build
```

Без Docker (Python 3.11+):

```bash
pip install -r requirements.txt
set -a; . ./.env; set +a
python -m bot
```

База SQLite хранится в `data/bot.db`.

## Команды

Пользователь: `/start`, `/status`, `/link`, `/help`.

Админ: `/grant <user_id> <дней>`, `/revoke <user_id>`, `/signal <текст>` (или ответ `/signal` на сообщение с фото, чтобы переслать его в канал).

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```
