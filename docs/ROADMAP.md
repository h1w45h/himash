# План разработки

## MVP (≈ 8–10 недель)
1. Монорепо, CI, Expo-каркас, тема светлая/тёмная, UI-кит, i18n (ru).
2. Clerk: email + Google + Apple; профиль, онбординг.
3. Каталог игр (seed из БД, кэш оффлайн), экран игры с правилами.
4. game-engine core + **Шахматы**, **Дурак**; боты EASY/MEDIUM; pass-and-play.
5. Комнаты по коду, лобби, Socket.io-слой, реконнект, таймеры ходов.
6. Матчмейкинг для 2 игроков, рейтинг Glicko-2, история партий.
7. Звуки, вибрация, базовые анимации. Closed beta в TestFlight / Google Play Internal.

## v0.5 — социальное (+4 недели)
Друзья, приглашения, чат (комната/ЛС), push-уведомления, VK-вход, достижения, **Монополия**, Шашки, Uno, Нарды.

## v0.8 — контент (+6 недель)
Го, Покер (Холдем), Преферанс, Свинтус, Catan, Каркассон, Ticket to Ride, Азул, Манчкин; боты HARD/EXPERT.

## v0.9 — пати и турниры (+4 недели)
Мафия, Бункер, Кодовые имена, Элиас, Диксит, Имаджинариум (голосовые/одновременные ходы); турниры
(single elimination → swiss), приват-турниры, лидерборды.

## v1.0 — монетизация и полировка (+4 недели)
Магазин (монеты/кристаллы, IAP через RevenueCat/StoreKit/Billing), косметика, ежедневные бонусы,
реплеи, модерация и жалобы, аналитика, нагрузочные тесты (k6), a11y, публикация в App Store / Google Play.

## Definition of Done для каждой игры
Правила на русском · серверная валидация · бот ≥ 2 уровней · pass-and-play (если применимо) · тесты движка ·
UI с анимациями · звуки/вибрация · запись в seed `Game` · достижения.
