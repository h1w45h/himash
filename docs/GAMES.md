# Как добавить игру

1. **Каталог:** запись в `packages/shared/src/catalog/*.ts` (название, правила на русском, число игроков, `status`).
   Для скрытой информации выставьте `hiddenInfo: true`.
2. **Движок:** `packages/game-engine/src/games/<slug>/index.ts` — объект `GameDefinition` (чистые функции, состояние сериализуется в JSON).
   Зарегистрируйте в `games/index.ts` (`BUILTIN`). Скрытую информацию вырезайте в `view(state, seat)`.
3. **Тесты движка** (обязательно): сценарии правил + «случайные партии» с проверкой инвариантов и завершения;
   для игр с эталонами — перфт-подобные проверки (как в шахматах).
4. **Интерфейс:** компонент `GameUIProps` в `apps/mobile/src/games/<slug>/`, регистрация в `games/registry.tsx`.
   Пока интерфейса нет, работает `GenericBoard` (состояние + список допустимых действий).
5. `npm run prisma:seed -w @nastolki/server` — игра появится в БД и в каталоге со статусом `BETA`.

Онлайн, оффлайн, боты, рейтинг, таймеры, реконнект и чат работают без дополнительного кода.
