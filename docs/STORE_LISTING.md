# Карточки приложения (RU)

**Название:** Настолки Онлайн: игры с друзьями (≤ 30 символов для iOS: «Настолки Онлайн»)
**Подзаголовок (iOS, ≤ 30):** Шахматы, Дурак, Монополия
**Краткое описание (Google, ≤ 80):** 21 настольная игра онлайн: шахматы, дурак, покер, монополия, мафия и другие.
**Ключевые слова (iOS, ≤ 100):** настолки,шахматы,дурак,покер,монополия,нарды,шашки,мафия,преферанс,уно,го,каркассон,катан

## Полное описание
Настольные и карточные игры в телефоне — с друзьями, случайными соперниками и ботами.

• 21 игра: шахматы, шашки, нарды, Го, дурак (подкидной и переводной), покер, преферанс, Uno, свинтус, монополия, колонизаторы, каркассон, Ticket to Ride, азул, манчкин, мафия, бункер, кодовые имена, элиас, диксит, имаджинариум.
• Онлайн-матчи: быстрый подбор соперника, комнаты по коду, приватные игры, турниры.
• Играйте с ботами четырёх уровней — даже без интернета; или вдвоём на одном устройстве.
• Друзья, чат, приглашения, push-уведомления о вашем ходе.
• Рейтинг Glicko-2, достижения, ежедневные бонусы, магазин косметики за монеты.
• Светлая и тёмная темы, звуки и вибрация.

## Категории
iOS: Игры → Настольные (дополнительно: Карточные). Google Play: Игры → Настольные.

## Возрастной рейтинг
12+/PEGI 3–7: нет насилия и азартных игр на деньги (покер — на внутриигровые монеты, без вывода). Контент в чате пользовательский — фильтр мата включён, есть блокировка и жалобы.

## Анкеты конфиденциальности
- Собираем: email, имя, идентификатор пользователя, игровой контент (сообщения), идентификатор устройства для push. Не продаём, не используем для рекламы.
- Шифрование при передаче: да (HTTPS/WSS). Удаление данных: в приложении (Профиль → «Удалить аккаунт»).
- Ссылки: политика — `https://<домен>/privacy`, поддержка — `/support`, условия — `/terms`.
- Apple: «Sign in with Apple» реализован через Clerk; ITSAppUsesNonExemptEncryption = false.
