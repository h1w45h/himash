# Экраны и навигация

Навигация — Expo Router. Корневой `_layout` проверяет сессию Clerk: нет сессии → `(auth)`, есть → `(tabs)`.

## Дерево

```
/(auth)
  welcome            — приветствие, кнопки: Email, Google, Apple (iOS), VK
  sign-in / sign-up  — форма email + пароль / код из письма
  forgot             — восстановление пароля
  onboarding         — выбор ника, аватара, любимых игр, разрешение push

/(tabs)
  index  «Главная»   — «Продолжить партию», ваш ход, ежедневный бонус, рекомендации, турниры
  games  «Игры»      — каталог: поиск, фильтры (категория, число игроков, время, сложность)
  play   «Играть»    — быстрый старт: онлайн / по коду / с ботом / на одном устройстве
  friends«Друзья»    — друзья, онлайн-статус, заявки, поиск, приглашения
  profile«Профиль»   — аватар, рейтинги, статистика, достижения, история, настройки

/game/[slug]         — карточка игры: описание, правила (RU), варианты, рейтинг-топ, кнопки режимов
/game/[slug]/setup   — настройка партии: вариант, число игроков, уровень бота, таймер, приватность
/rooms               — список открытых комнат с фильтрами; «Создать комнату»; «Войти по коду»
/room/[code]         — лобби: места, готовность, чат, приглашение друзей, запуск
/match/[id]          — онлайн-партия (доска, HUD, таймер, чат, предложение ничьей/сдача, реконнект)
/local/[slug]        — pass-and-play (экран передачи устройства для скрытой информации)
/bot/[slug]          — партия с ботом (EASY…EXPERT), автосохранение
/match/[id]/result   — итоги: рейтинг ±, награды, реванш
/match/[id]/replay   — реплей по журналу ходов
/matchmaking         — поиск соперника (анимация, отмена, расширение окна)
/tournaments         — список: открытые, мои, завершённые
/tournament/[id]     — сетка, участники, расписание, чат
/tournament/create   — создание (формат, приз, приват-код)
/shop                — вкладки: Аватары, Темы досок, Рубашки карт, Эмоции, Наборы; баланс; IAP
/shop/item/[id]      — предпросмотр, покупка, «Применить»
/user/[id]           — чужой профиль: статистика, добавить в друзья, пригласить, пожаловаться
/chat/[userId]       — личные сообщения
/notifications       — центр уведомлений
/leaderboard/[slug]  — лидерборд по игре (глобальный / друзья)
/settings            — тема (светлая/тёмная/системная), звук, вибрация, push, приватность, аккаунт, выход
/settings/account    — смена ника/email, привязка провайдеров, удаление аккаунта
```

## Потоки

1. **Быстрая игра:** Играть → выбрать игру → Онлайн → `/matchmaking` → `/match/[id]` → итоги → реванш/в лобби.
2. **По коду:** Играть → «Войти по коду» → `/room/[code]` → готов → старт хоста.
3. **Приглашение друга:** Друзья → профиль друга → «Пригласить» → push → deep link `nastolki://room/ABC123`.
4. **Pass-and-play:** игра → «На одном устройстве» → `/local/[slug]`; для скрытых карт — экран «Передайте телефон: Игрок 2».
5. **Оффлайн:** вкладки «Игры», «Играть → Бот/Локально», «Профиль (кэш)»; онлайн-кнопки неактивны с пояснением.

Deep links: `nastolki://room/<code>`, `nastolki://match/<id>`, `nastolki://user/<id>`, `nastolki://tournament/<id>`.
